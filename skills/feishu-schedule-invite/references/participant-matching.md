# 参与人匹配规则

## 识别方式

### 1. 姓名
- "影子" → 搜索姓名包含"影子"的用户
- "卓洛" → 搜索姓名包含"卓洛"的用户
- "阿振(Pz)" → 可识别为"阿振"或"Pz"

### 2. 部门/团队
- "前端组" → 搜索前端组所有成员
- "得技力团队" → 搜索得技力团队所有成员

### 3. 群聊
- "2026Q2目标对齐群的成员" → 获取群聊所有成员
- 使用 `feishu_chat_members` 获取群成员列表

### 4. 角色
- "我老板" → 从组织架构中查找直属上级
- "我的组员" → 查找当前用户下属

### 5. 代词
- "我" → 当前用户自己
- "我们" → 当前用户 + 上下文相关成员

---

## 匹配流程

1. 使用 `feishu_search_user` 搜索用户
2. 如果找到唯一匹配，直接使用
3. 如果找到多个匹配，展示列表让用户选择
4. 如果找不到，提示用户提供更准确的信息

---

## ⚠️ 重要：必须确认参与人

> **参与人列表必须向用户确认后再继续**

即使识别成功，也要展示参与人列表让用户确认：

```
助手: 参与人确认（共10人）：
- 阿振、小平、居右、洋洋、孤城、川禾、山筑、玛卡、魏命名、弗罗格

是否正确？
```

## 示例

### 示例 1：唯一匹配

```
用户: 约明天下午和影子、卓洛开个会

助手: 我找到了以下参与人：
- 影子(Phantom) - 技术平台
- 卓洛(yihong) - 国际技术
- 你

请确认是否正确？
```

### 示例 2：多个匹配

```
用户: 约张伟开个会

助手: 我找到了多个名为"张伟"的用户：
1. 张伟(前端组)
2. 张伟(后端组)
3. 张伟(测试组)

请问您指的是哪一位？
```

### 示例 3：群聊成员

```
用户: 约目标对齐群的成员开个会

助手: 我找到了"2026Q2目标对齐"群，共10人：
- 阿振、小平、居右、洋洋、孤城、川禾、山筑、玛卡、魏命名、弗罗格

请确认是否正确？
```

### 示例 4：找不到用户

```
用户: 约小明开个会

助手: 抱歉，我没有找到名为"小明"的用户。
请问能否提供更多信息，如：
- 全名
- 部门
- 职位
```
