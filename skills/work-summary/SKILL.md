# 工作日报生成


## 输出格式（必须严格遵循）

### 格式一：今日工作总结

根据时间线内容，聚合为有逻辑的工作块，每块包含时间和耗时：

```
- 9:00-9:30 和 xxx 完成了绩效考核事项沟通（耗时 0.5h）
- 10:00-12:00 进行了 xxx 项目开发，完成核心功能（耗时 2h）
- 14:00-16:30 参加 Q2 OKR 对齐会议（耗时 2.5h）
```

**维度标签**：
- 【飞书】- 飞书消息沟通
- 【会议】- 参加的会议（从智能纪要获取）
- 【浏览器】- 浏览器访问记录
- 【飞书文档】- 飞书文档操作（创建/编辑/打开）
- 【Git】- 代码提交记录
- 【Agent】- AI Agent 会话（Cursor/ClaudeCode/OpenCode）


### 格式二：待办事项

从聊天记录、会议内容和承诺消息中提取，包括明确截止时间的：

```
- 下周五前：完成 Q2 OKR 目标对齐
- 今天答应了 xxx：帮忙 review 他的 MR
```

### 格式三：今日时间线

按时间顺序排列，每个条目包含时间范围、维度、内容：

```
- 9:00-9:30【飞书】和 xxx 沟通绩效考核事项
- 10:00-10:30【浏览器】查看 xxx 技术文档
- 10:30-11:00【会议】参加得技力 AI 推进双周会
- 11:00-12:00【Git】提交 feat: 完成 xxx 功能
```

## 数据采集

### 第一步：获取当前日期

确定日期，默认今天，格式 YYYY-MM-DD。

### 第二步：采集六类数据

**飞书消息**：执行 `feishu-message-deepsearch`，搜索今天用户发送的所有消息，按时间升序排列。

**飞书文档**：执行 `feishu-docs-deepsearch`，按编辑时间排序，筛选今天用户创建或编辑的文档。

**浏览器历史**：执行 `browser-history-search` 脚本获取今天的浏览器访问记录。

**Git 提交**：执行 `git-commits-search` 脚本获取今天的代码提交记录。

**会议智能纪要**：通过以下步骤获取今天参加的会议内容：
1. 调用 `feishu_calendar_event` 的 `instance_view`，获取今日所有日历事件
2. 搜索与"智能纪要助手"（bot app_id: `cli_a0d9f8eba778d00e`）的私聊消息，找到今天它发给用户的文档链接（type=docx 的消息）
3. 调用 `feishu_fetch_doc` 读取文档内容，提取会议主题、时间、参会人、主要内容和待办事项
4. 如有多个会议，重复此步骤

**Agent 会话**：执行 `agent-sessions-search` 脚本获取今天 Agent 会话记录

解析返回内容，提取：
- 会话时间范围（start_time - end_time）
- 使用的 Agent 类型（cursor / claaude-code / opencode）
- 每个会话中用户提出的任务/问题（从 user 消息提取）
- Agent 完成的工作内容（从 assistant 消息提取，识别文件编辑、代码生成、问题修复等）

### 第三步：数据解析

将六类数据统一转换为时间线格式：
- 每条记录包含：时间、内容、维度、数据来源
- 按时间升序排列
- 合并同一时间段内的连续活动
- 会议时间直接使用日历中的时间
- Agent 会话时间直接使用会话的 start_time - end_time

### 第四步：生成总结

从时间线中提取：
- 主要工作事项（按时间顺序列出）
- 承诺/答应别人的事（从消息中识别）
- 有明确截止时间的事项
- 从会议智能纪要中提取待办事项
- 从 Agent 会话中识别完成的功能/修复/任务

### 第五步：输出

输出为三个格式板块，全部用中文。

生成完日报后，**必须**同时保存到本地文件：

```
路径：~/.openclaw/workspace/memory/YYYY-MM-DD.md
```

保存内容包含：
1. 标题：`# YYYY-MM-DD Daily Memory`
2. `## 工作总结` section：今日工作总结
3. `## 待办事项` section：待办事项
4. `## 时间线` section：今日时间线

如果文件已存在，追加到现有内容后面；如果不存在，创建新文件。

## 会议智能纪要获取详细步骤

### Step 1: 查询今日日历

```typescript
feishu_calendar_event({
  action: "instance_view",
  start_time: "2026-04-09T00:00:00+08:00",
  end_time: "2026-04-09T23:59:59+08:00"
})
```

返回今日所有日历事件，包含 event_id、summary（会议标题）、start_time、end_time。

### Step 2: 搜索智能纪要助手的消息

```typescript
feishu_im_user_search_messages({
  query: "",  // 不需要关键词
  sender_type: "bot",
  relative_time: "today"
})
```

然后筛选 sender.id 为 `cli_a0d9f8eba778d00e`（智能纪要助手）的消息，提取 msg_type=text 的消息内容（这是文档链接）。

### Step 3: 读取文档内容

```typescript
feishu_fetch_doc({
  doc_id: "文档链接URL或token"
})
```

读取后提取：
- `title` - 会议主题
- `meeting_time` - 会议时间
- `attendees` - 参会人
- `summary` - 会议主要内容
- `todo` - 待办事项

## 注意事项

1. **时间线必须完整**：六类数据都要采集，不能遗漏
2. **时间范围**：当天 00:00 - 23:59
3. **承诺消息识别**：特别留意"好的"、"可以"、"我来弄"等回复，这些可能是答应了别人的事
4. **耗时计算**：根据时间线估算每项工作的耗时
5. **输出语言**：全部使用中文
6. **会议数据优先**：如果智能纪要中有待办事项，优先提取到待办列表中
7. **Agent 会话解析**：从会话内容中识别用户让 AI 完成的具体任务，如"完成 xxx 功能"、"修复 xxx bug"、"重构 xxx 模块"等，提取为独立时间线条目
